# Thinking Suite — for humans

This directory contains the full reasoning skill system, written for human readers. Same skills, same structure, same discipline as the `for-agents/` version — without AI-specific notation. No depth percentages, no routing signals. Just the practices.

---

## How to start

**Read `skill-master.md` first.** Five questions you ask before engaging with any problem that matters. Everything else builds on the discipline this establishes.

**Then read `conductor.md`.** It explains how to move between skills — when to switch, how to know you're done.

**Then read `topology.md` if you want to understand how the skills relate to each other.** It's the map. Use it when you're not sure what comes next.

**Then use whichever skill the situation calls for.**

## How the skills work together

The skills sit in layers that reflect the natural flow of thinking:

**Detection** — something feels off but you don't know what yet
→ *discrepancies*

**Framing** — you're not sure you're solving the right problem
→ *reframe*, *decompose*

**Generation** — the problem is clear but unexplored
→ *speculate*, *infer*, *steelman*

**Testing** — you have a position that needs pressure
→ *reconsider*, *challenge*, *constrain*

**Synthesis** — you've explored enough and need to integrate
→ *review*, *pre-mortem*

Most thinking that fails does so because it skips layers — jumping to testing before framing is right, or generating without ever testing. The conductor helps you stay honest about where you are.
