# Thinking Suite

A reasoning skill system — 15 tools for thinking more clearly, structured for both AI agents and human thinkers.

---

## What this is

A complete, modular framework for deliberate reasoning. Each skill is a specific cognitive operation: detecting anomalies before you know what's wrong, breaking tangled problems into parts, constructing the strongest version of a position you disagree with, stress-testing a decision before you commit.

The skills work individually and together. The system has a architecture: **skill-master** is the master lens applied before any substantive thinking; **conductor** is the director that routes between skills; **topology** maps how all skills relate in three dimensions. Every other skill is a specific application of the same underlying discipline.

---

## Two versions

### [`for-agents/`](for-agents/)
The original system, written for AI reasoning systems. Technical notation (lens, depth, light intensity parameters), explicit routing signals, integration instructions for the conductor. Use this if you are building an agent or want the full architectural specification.

### [`for-humans/`](for-humans/)
The same system, rewritten for human readers. Same skills, same structure, same discipline — without the AI-specific notation. Use this if you are a person who wants to think more carefully.

Both versions are complete. Start with `skill-master` in whichever directory applies to you.

## The 15 skills

| Skill | What it does |
|-------|-------------|
| **skill-master** | The master lens — five questions before any substantive response |
| **conductor** | Director of the system — routes between skills, watches the whole |
| **topology** | Three-dimensional map of how all skills relate |
| **kaleidoscope-guide** | The operating manual — how the system works in practice |
| **discrepancies** | Detect where reality doesn't match the model, before you know why |
| **reframe** | Step outside the current problem frame when the frame is the obstacle |
| **decompose** | Break a tangled problem into named, workable parts |
| **speculate** | Generate possibilities without committing to any |
| **infer** | Reason carefully from incomplete information |
| **steelman** | Construct the strongest version of a position you disagree with |
| **reconsider** | Re-examine a conclusion you've already reached |
| **challenge** | Test a position against the strongest possible objections |
| **constrain** | Find exactly where a principle applies and where it breaks |
| **review** | Synthesize multiple perspectives into emergent understanding |
| **pre-mortem** | Surface concrete failure modes before committing to a decision |

## How to start

Read **skill-master** first. It is the foundation the rest of the system builds on.

Then read **conductor** to understand how the skills work together.

Then use whichever skill the situation calls for.
